这是 MAXCELLENT 迈瑟伦的原材料价格监测与采购预警项目，用于跟踪应急启动电源相关的电池、PCBA、线材夹子、充气泵、塑料外壳、包装等核心成本项。

## 本地智能分析助手

新增了一个本地-only 的大模型联网智能体入口：

- 页面入口：`打开大宗商品智能分析助手.cmd`
- Key 配置：`配置大宗商品智能分析助手Key.cmd`
- 联网诊断：`检查大宗商品智能分析助手联网状态.cmd`
- 研究链路试跑：`试跑大宗商品智能分析助手研究链路.cmd`
- 整体验证：`验证大宗商品智能分析助手.cmd`
- 后端脚本：`scripts/commodity_agent_server.py`
- 使用说明：`docs/AI_AGENT_LOCAL.md`

新增的本地工作流：
- 最近会话会保存在 `runtime/agent/sessions.json`
- 左侧可以回看最近分析会话
- 当前会话可以导出为本地 Markdown 纪要，输出到 `runtime/agent/exports/`
- 双击助手入口时会先检查后台是不是当前这版服务；如果还是旧进程，会自动重启后再打开页面
- 左侧 `联网设置` 现在可以直接保存本地 OpenAI key / Base URL / 模型配置，并当场验证联网状态，不需要再回命令行
- 左侧 `联网设置` 现在也可以直接切换“仅使用本地分析”，不需要再手动改 `COMMODITY_AGENT_FORCE_LOCAL_ONLY`
- 左侧现在还多了 `试跑研究链路`，可以直接验证这套智能体有没有沿真实研究问答主链路同时跑通本地联网状态读取和外部公开来源补证
- 最近一次联网验证 / 试跑结果会保存在 `runtime/agent/network_checks.json`，左侧会直接显示最近诊断摘要
- `配置大宗商品智能分析助手Key.cmd` 现在会保留你没改的旧配置字段，保存后还可以直接联动跑联网诊断

这个助手会优先读取本地公开监测结果 `data/latest.json` 和最近简报，再按需要通过 OpenAI Responses API 的 `web_search` 联网补充当天外部信息。它不会把 API key 暴露到 GitHub Pages，也不会读取 `.private/`、`data/internal/`、`runtime/internal/`。

从 `2026-06-19` 这轮补强起，如果 `dashboard/data.js` 这份同步后的本地看板副本已经比 `data/latest.json` 更新，智能体分析会优先读取这份更鲜的 payload，并在“今日快照”“本地依据”和 `local_summary` 里明确标出当前分析实际站在哪个本地数据源上。现在 `/api/status` 和 `/api/network-readiness` 里的“当前分析快照”也会跟着显示这份实际生效的时间与来源，避免页面已经优先用了更新数据、状态卡却还停留在旧 `latest.json` 时间上；只有刷新健康诊断本身，仍然单独保留真实 `data/latest.json` 与公网时间的对比口径。

现在页面启动后会先显示“今日快照”，把本地最新刷新时间、成本压力指数、重点盯盘品种、涨幅靠前品种和建议动作先摆出来；即使还没配置 key，也能先看本地监测概览，再决定要不要继续做联网分析。

智能体后端已经接入本地函数工具，模型可以按需精确读取单个材料明细、成本大类和最近简报，而不是只依赖一整段静态上下文；页面也会显示这轮回答实际用了哪些本地工具和联网检索能力。

现在还补上了“无 key 本地回退分析”链路：如果当前没有配置 OpenAI key，或者手动启用了 `COMMODITY_AGENT_FORCE_LOCAL_ONLY=1`，助手仍会基于本地公开监测、累计历史、最近简报和已缓存新闻生成完整分析，不会只剩一个快照壳子。

最近又补了一段多材料对比能力：像“铜、铝、ABS 谁更该盯”“哪些是真实行情，哪些只是代理指标”“谁的中期趋势更强”这类问题，助手现在会优先走专门的本地对比工具，而不是只拼一段泛化描述。

这轮又把“今日盯盘清单 / 异常关注项”做成了独立能力：像“今天先盯哪几个原材料”“给我一个优先级清单和理由”“哪些材料今天该排在第一批关注名单里”这类问题，助手会优先调用专门的本地盯盘清单工具，把优先级、原因、传导链和动作拆开讲清楚。

这轮也把“昨日对比 / 今日变化摘要”做成了独立能力：像“和昨天比今天重点变化是什么”“哪些材料今天变动最大”“今天相较前一档最值得注意的差异在哪”这类问题，助手会优先调用专门的本地变化摘要工具，把日变化、前次价格、风险、传导链和动作拆开组织出来。

现在也补上了“联网就绪诊断”能力：像“为什么现在还是本地模式”“帮我检查联网配置和 key 状态”“现在能不能走联网研究”这类问题，助手会优先读取本地联网状态、key 来源、强制本地模式开关和刷新底座状态，直接指出卡点和下一步动作。
从这轮补强起，左侧 `联网设置` 里还新增了“保存并自动推进联网验收”。如果刚填入真实 key，不用再自己逐个点“验证联网”“试跑研究链路”“运行最终联网验收”；页面会按当前状态顺着往下跑，并在满足条件时直接启动最终联网验收。

现在也补上了“未来走势 / 情景展望”能力：像“未来一周成本压力会不会抬升”“未来一个月更像上行情景还是基准情景”“现在更适合提前询价、分批备货还是继续观察”这类问题，助手会优先基于本地公开监测、累计历史和新闻信号，给出 7/30/90/180/365 天的场景判断、领先情景概率和对应策略。

联网模式这边也补了一层稳态：对于“新闻驱动解释”和“未来走势/情景展望”这类问题，首轮发给模型的本地上下文里就会先带上对应的本地摘要，减少模型漏掉本地监测证据、完全只按外部搜索回答的概率。
从这轮补强起，“多材料对比”和“采购动作建议”这两类研究问法也会在首轮上下文里直接带上对应的本地对比摘要 / 动作摘要，并额外给模型一行明确的“建议优先调用本地工具”，减少研究模式下把该走的本地工具漏掉、直接空泛联网检索的概率。

现在每轮回答里还会显式展示“本地依据”，把这轮结论主要依赖的本地快照、重点材料、成本大类、最近简报、刷新健康或联网诊断记录单独列出来，避免后续回看时只看到结论、不清楚它站在哪一版本地监测结果上。

## 数据安全

公网看板只展示公开行情、明确标注的上游代理指标和风险提示。BOM、供应商报价、库存、采购价、销售数据、图纸等内部资料只允许进入本地或权限受控的内部看板，不上传到公网 GitHub Pages。

价格口径必须区分：

- `真实行情`：公开市场可取得的现货、期货或基准价。
- `上游代理指标`：使用真实上游价格监控趋势，但不是该材料的直接报价，不能当成该材料真实成交价。
- `供应商报价`：公司内部或供应商人工补录价格，只在本地内部看板使用。

已忽略的本地内部目录：

- `.private/`
- `data/internal/`
- `outputs/internal/`
- `runtime/internal/`
