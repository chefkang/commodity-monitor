# 采购计划与备货计划模型蓝图

这个文档定义“原材料价格监测看板”下一阶段如何升级为采购决策系统。目标不是只看价格，而是让老板每天能回答：

- 哪些物料要马上买？
- 哪些物料可以等等？
- 哪些供应商报价需要复核？
- 半年到一年内哪些核心物料适合锁价或战略备货？

## 1. 总体逻辑

采购建议由五类信息共同决定：

```text
采购动作 = 原材料行情风险
       + 产品BOM成本影响
       + 当前库存与在途
       + 销售/生产消耗预测
       + 供应商交期、MOQ、账期和报价
```

公网行情只能回答“外部价格可能怎么走”。真正的采购计划必须接入公司内部数据后才能回答“我们该买多少”。

## 2. 数据分层

### 2.1 外部行情层

已覆盖的公开行情和代理指标。看板必须明确区分真实行情和上游代理指标：代理指标只能用于趋势预警，不能作为该材料的直接成交价或供应商报价。

- 电池相关：碳酸锂、磷酸铁锂正极代理、铜箔代理、铝箔代理、电解液/六氟磷酸锂代理。
- PCBA相关：铜、PCB铜箔代理、玻纤布/电子布、环氧树脂、双酚A、环氧氯丙烷、锡、焊锡/锡膏代理。
- 线材夹子相关：铜、PVC、硅胶/DMC、工业硅、橡胶、钢件、镀镍、锌。
- 充气泵相关：铜、铝、钢材、铁矿石、PVC软管、橡胶。
- 塑料外壳相关：ABS、PC、PP、PVC、LLDPE、苯乙烯。
- 包装相关：瓦楞纸、纸浆、废纸。

输出字段：

- 最新价格
- 1日、7日、30日、90日涨跌幅
- 涨价风险
- 新闻扰动
- 数据来源
- 价格口径：真实行情 / 上游代理指标 / 供应商报价

### 2.2 BOM映射层

把产品SKU拆成物料，建立“行情品种 → 物料 → 产品 → 成本影响”的链路。

示例：

```text
铜价上涨
  → 铜线、铜夹、PCB铜箔、电机铜线
  → 启动夹、线束、PCBA、充气泵
  → 应急启动电源整机成本上升
```

每个BOM行至少需要：

- SKU
- 物料编码
- 物料名称
- 单台用量
- 单位
- 损耗率
- 当前采购单价
- 供应商
- 对应行情指标

### 2.3 库存消耗层

核心指标：

```text
日均消耗 = 近N天销售/生产消耗数量 / N
可用库存 = 当前库存 + 可用在途 - 已锁定数量
库存可撑天数 = 可用库存 / 日均消耗
交期需求量 = 日均消耗 * 供应商交期天数
安全库存 = 日均消耗 * 安全天数 * 波动系数
补货点 = 交期需求量 + 安全库存
净需求 = 预测期需求 + 安全库存 - 当前库存 - 在途采购
```

建议先用 30 天、90 天、180 天、365 天四个周期。

### 2.4 供应商约束层

每个物料的采购动作必须受供应商约束影响：

- MOQ 最小起订量
- 价格阶梯
- 交期
- 账期
- 可否锁价
- 是否独家供应
- 品质稳定性
- 历史准交率
- 最近报价日期

### 2.5 决策输出层

每个物料输出一个采购动作：

| 动作 | 触发条件 |
| --- | --- |
| 立即补货 | 库存天数低于交期，且涨价风险中高 |
| 分批补货 | 库存一般，价格风险中等，需求稳定 |
| 锁价谈判 | 成本占比高，涨价概率高，供应商支持周期价 |
| 暂缓采购 | 库存充足，价格下行或需求不确定 |
| 供应商复核 | 供应商涨价明显高于行情涨幅 |
| 替代料评估 | 单一供应、交期拉长、行情或新闻风险高 |

## 3. 采购风险评分

建议建立 0-100 分的采购优先级。

```text
采购优先级 =
  行情涨价风险 * 25%
+ 库存短缺风险 * 25%
+ 产品成本影响 * 20%
+ 未来需求强度 * 15%
+ 供应商交付风险 * 10%
+ 新闻扰动风险 * 5%
```

分数解释：

- 80-100：立即处理，进入老板重点盯盘。
- 65-79：建议一周内处理，重点询价或分批备货。
- 50-64：保持关注，等待更明确价格或订单信号。
- 0-49：暂不动作，只做日常跟踪。

## 4. 半年/一年预测方法

长期预测不应输出“确定会涨多少”，而应输出情景概率。

### 4.1 四种情景

| 情景 | 含义 | 采购策略 |
| --- | --- | --- |
| 下行情景 | 原材料走弱，供应宽松 | 降低库存，压供应商价格 |
| 基准情景 | 价格震荡，需求正常 | 按补货点滚动采购 |
| 上行情景 | 多项核心材料上涨 | 分批备货，重点物料谈锁价 |
| 极端情景 | 国际冲突、停产、出口限制 | 提前锁定供应和替代料 |

### 4.2 长周期输出

每月滚动生成：

- 30天采购动作
- 90天备货计划
- 180天战略备货建议
- 365天关键物料风险清单

## 5. 看板升级模块

下一阶段内部版看板建议新增：

1. 物料库存天数排行
2. 未来30/90/180天建议采购量
3. 产品SKU成本压力排行
4. 供应商报价偏离行情提醒
5. 战略备货清单
6. 锁价谈判清单
7. 现金占用与缺货风险对比
8. 主销产品毛利压力预警

## 6. 数据安全原则

- 公网页面只展示公开行情和代理指标。
- BOM、供应商、库存、采购价、销售数据只进入内部版看板。
- 内部版默认本地运行，后续如需公网访问，必须加登录权限。
- 所有导出数据先脱敏或放入 `data/internal/`，该目录已被 Git 忽略。
