# 采购与备货核心公式

这个文档记录系统后续计算采购计划时使用的统一口径。

## 1. 基础数量

```text
可用库存 = 账面库存 - 已锁定库存 + 可用在途
```

```text
日均消耗30 = 近30天实际消耗 / 30
日均消耗90 = 近90天实际消耗 / 90
```

如果销量波动大，默认使用：

```text
计划日均消耗 = max(日均消耗30, 日均消耗90 * 0.8, 未来订单日均需求)
```

## 2. 库存天数

```text
库存可撑天数 = 可用库存 / 计划日均消耗
```

如果计划日均消耗为 0，库存天数显示为“低消耗/待确认”，不直接给出高置信采购建议。

## 3. 补货点

```text
交期需求量 = 计划日均消耗 * 供应商交期天数
安全库存 = 计划日均消耗 * 安全天数 * 波动系数
补货点 = 交期需求量 + 安全库存
```

默认安全天数：

| 物料类型 | 安全天数 |
| --- | --- |
| 电池包核心材料 | 30 |
| PCBA核心材料 | 30 |
| 线材夹子 | 25 |
| 充气泵材料 | 25 |
| 塑料外壳 | 20 |
| 包装耗材 | 15 |

## 4. 建议采购量

```text
预测期需求 = 计划日均消耗 * 预测天数
建议采购量 = max(0, 预测期需求 + 安全库存 - 当前库存 - 在途数量)
```

预测天数默认使用：

- 30天：短线补货
- 90天：季度备货
- 180天：战略备货
- 365天：年度风险规划

## 5. 采购动作判断

### 立即补货

```text
库存可撑天数 <= 供应商交期天数 + 7
并且 采购优先级 >= 65
```

### 分批补货

```text
库存可撑天数 <= 供应商交期天数 + 安全天数
并且 采购优先级在 50-79
```

### 锁价谈判

```text
成本影响权重高
并且 行情涨价风险 >= 65
并且 供应商支持锁价
```

### 暂缓采购

```text
库存可撑天数 > 90
并且 行情涨价风险 < 50
```

### 供应商复核

```text
供应商报价涨幅 - 对应行情涨幅 >= 3个百分点
或 供应商报价连续两次上调但行情未上行
```

## 6. 老板看板输出

每个物料最终要输出：

- 当前库存可撑天数
- 30天建议采购量
- 90天建议采购量
- 180天战略备货建议
- 采购优先级
- 建议动作
- 影响SKU
- 主要供应商
- 价格来源与代理关系
- 风险解释
