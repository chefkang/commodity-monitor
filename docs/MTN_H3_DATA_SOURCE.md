# 美途能进销存系统数据源说明

本项目的采购计划和备货计划以钉钉内的 **美途能进销存系统** 为最高可信来源。

## 数据源优先级

1. 美途能进销存系统：采购、供应商、原材料、库存、入库、出库、生产等真实经营数据。
2. 公司公共盘现有库存/BOM 表：当进销存导出尚未落地时，用作过渡基线。
3. 手工模板：只用于字段补充和人工校准。

`【采购管理系统】` 当前仍在搭建，表内数据不足，暂不作为采购计划主数据源。

## 采购备货模型所需表

| 业务用途 | 进销存模块 | 标准表 |
| --- | --- | --- |
| 采购在途、采购额、未付款、预计交期 | 物料采购 / 采购下单 | `purchase_orders` |
| 到货和物流状态 | 物料采购 / 采购订单跟踪 | `purchase_tracking` |
| 供应商与付款方式 | 供应商管理 | `supplier_master` |
| 物料编码、规格、分类、标准价 | 原材料管理 | `material_master` |
| 当前库存与盘点 | 库存管理 / 库存盘点 | `inventory_count` |
| 真实消耗速度 | 库存管理 / 物料出入库明细 | `inventory_movements` |
| 采购入库 | 入库管理 | `inbound_receipts` |
| 生产领料与报废出库 | 出库管理 | `outbound_issues` |

## 内部文件位置

导出的氚云 Excel/CSV 文件放在：

```text
data/internal/h3_exports/
```

运行导入脚本后，标准化结果会生成在：

```text
data/internal/h3_normalized/
```

这两个目录被 Git 忽略，不会发布到 GitHub Pages，也不会进入公网看板。

## 当前接入策略

- 每天公开看板继续展示大宗行情、新闻风险和公开价格趋势。
- 本机内部看板用于老板采购决策，融合进销存、BOM、库存与价格风险。
- 当进销存导出文件缺失时，内部测算会自动降级为公共盘库存/BOM基线，并明确标记数据源。
